# 🚀 Visual Builder - Quick Start Guide

## Getting Started in 5 Minutes

### 1. Open the Builder
```
Open builder.html in your web browser
```

### 2. Understand the Interface
```
┌─────────────────────────────────────────────────────┐
│ Toolbar: [Undo] [Redo] [Save] [Preview] [Publish] │
├──────────┬──────────────────────┬───────────────────┤
│ Elements │   Preview Canvas     │   Properties      │
│ Tree     │   (Click to select)  │   Panel           │
│          │                      │                   │
│ ▼ Header │   [Website Preview]  │   [Edit Controls] │
│   Logo   │                      │                   │
│   Search │                      │   • Content       │
│   Nav    │                      │   • Dimensions    │
│          │                      │   • Colors        │
│ ▼ Hero   │                      │   • Effects       │
│   ...    │                      │   • Position      │
│          │                      │                   │
└──────────┴──────────────────────┴───────────────────┘
```

### 3. Select an Element
**Option A: Click in Preview**
- Click directly on any element in the preview
- Green border shows selection

**Option B: Use Element Tree**
- Click on element name in left sidebar
- Organized by section

### 4. Edit Properties
- **Content**: Change text, placeholders, titles
- **Dimensions**: Set width, height
- **Colors**: Pick text and background colors
- **Typography**: Font, size, weight
- **Effects**: Glass effect, shadows, animations
- **Spacing**: Margin and padding

### 5. Preview Changes
```
Click [Preview] button
→ Opens full-screen preview
→ Test on different devices
→ Verify all changes
```

### 6. Publish
```
Click [Publish] button
→ Changes saved to localStorage
→ Live website updates immediately
→ All tabs sync automatically
```

## Common Tasks

### Change Header Color
1. Select "Header" from element tree
2. In Properties panel → Colors
3. Click background color picker
4. Choose new color
5. Preview to verify
6. Publish

### Modify Search Bar
1. Click search bar in preview
2. Change "placeholder" text
3. Adjust "width" to 500px
4. Set border-radius to 25px
5. Enable glass effect
6. Publish

### Hide a Section
1. Find section in left sidebar
2. Toggle the switch to OFF
3. Preview to confirm
4. Publish

### Change Player Height
1. Select "Music Player" from tree
2. Find "height" property
3. Set to 90px
4. Preview
5. Publish

### Modify AI Assistant
1. Select AI Assistant FAB
2. Change position: bottom-left
3. Adjust size to 60px
4. Change color
5. Publish

## Pro Tips

💡 **Save Drafts Often**: Click Save Draft regularly
💡 **Use Undo**: Ctrl+Z to undo mistakes
💡 **Test Mobile**: Always check mobile view
💡 **Preview First**: Always preview before publishing
💡 **One Change at a Time**: Make incremental changes
💡 **Check Console**: Press F12 for debugging

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| Ctrl+Z | Undo last change |
| Ctrl+Y | Redo change |
| Ctrl+S | Save draft |
| Delete | Remove element |
| Escape | Deselect |
