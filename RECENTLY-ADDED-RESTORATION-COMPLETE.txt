HOW IT WORKS
═══════════════════════════════════════════════════════════════════

DATA FLOW:
1. Page loads → DataStore.init() runs
2. Checks if songs exist in localStorage
3. If not, loads 5 default published songs
4. script.js calls initRecentlyAdded()
5. Renders songs from DataStore.getSongs()
6. Filters by status === 'published'
7. Sorts by createdAt (newest first)
8. Displays in marquee carousel
9. Auto-updates when new songs added via Builder

AUTO-UPDATE BEHAVIOR:
• When you add songs via Builder with status: 'published'
• Songs automatically appear in Recently Added section
• New songs appear first (sorted by creation date)
• Section updates in real-time across all tabs

HOW TO USE
═══════════════════════════════════════════════════════════════════

VIEWING THE SECTION:
1. Open index.html in your browser
2. Scroll to the bottom of the page
3. See "Recently Added" section with 5 songs
4. Watch the marquee scroll right-to-left
5. Hover to pause on desktop
6. Touch/drag on mobile to interact

ADDING YOUR OWN SONGS VIA BUILDER:
1. Open builder.html
2. Go to Songs section
3. Add new song with these fields:
   - title: "Song Name"
   - artist: "Artist Name"
   - youtubeId: "YouTube Video ID"
   - albumCover: "Image URL (optional)"
   - duration: "3:45"
   - status: "published" ← CRITICAL: Must be 'published'
4. Save the song
5. It will automatically appear in Recently Added

ADDING SONGS DIRECTLY (Developer):
1. Open browser console (F12)
2. Run this code:

   const song = {
       id: 'song_' + Date.now(),
       title: 'Your Song Title',
       artist: 'Artist Name',
       album: 'Album Name',
       albumCover: 'https://...',
       duration: '4:20',
       status: 'published',
       createdAt: Date.now(),
       youtubeId: 'YouTubeVideoID'
   };
   
   const songs = DataStore.getSongs();
   songs.push(song);
   DataStore.setSongs(songs);
   initRecentlyAdded();

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

IF SECTION APPEARS EMPTY:
1. Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
2. Clear browser cache and reload
3. Check console (F12) for errors
4. Verify songs have status: 'published'
5. Check localStorage has 'tamilAIStream_songs' key

IF SONGS DON'T PLAY:
1. Verify youtubeId is correct
2. Check if YouTube video is available
3. Ensure playSong() function is not erroring
4. Check browser console for errors

IF MARQUEE NOT SCROLLING:
1. Check CSS animation is applied
2. Verify track has content
3. Check for JavaScript errors
4. Ensure CSS file loaded correctly
