PROBLEM:
--------
The splash screen was not appearing as a true full-screen overlay.
The website content was potentially visible behind or through the
splash screen.

ROOT CAUSE:
-----------
The JavaScript was missing the critical line to add the 'splash-active'
class to the <html> element. Without this class, the CSS rules to hide
the body (visibility: hidden, opacity: 0) were not being applied.

SOLUTION:
---------
1. Added immediate class addition in JavaScript:
   document.documentElement.classList.add('splash-active');

2. Enhanced CSS with !important flags and additional safeguards:
   - z-index: 999999999 (ultra-high, above everything)
   - position: fixed with all position properties
   - width/height: 100vw/100vh + 100dvw/100dvh
   - pointer-events: all (prevents clicks through)
   - overflow: hidden (prevents scroll)

3. Body hiding with multiple properties:
   - visibility: hidden !important
   - opacity: 0 !important
   - pointer-events: none !important
   - overflow: hidden !important
